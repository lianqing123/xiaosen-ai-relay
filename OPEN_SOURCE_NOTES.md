# Xiaosen AI Relay

This repository is a sanitized open-source snapshot of the AI relay gateway project.

Sensitive runtime files are intentionally excluded:

- `.env` and local environment files
- database files
- logs and backups
- private keys and certificates
- generated binaries and build outputs
- dependency folders such as `node_modules`

Use the example configuration files under `deploy/` as templates and provide secrets through your own deployment environment.
